02 / PERFORMANCE · CORE WEB VITALS

Fixing LCP: getting the main content on screen sooner

LCP measures how quickly the largest piece of content, usually a hero or product image, appears. Slow performance came first in the work: even strong pages struggle to rank on a slow site.

HTML · techniques applied

<!-- prioritize the LCP element -->
<link rel="preload" as="image" href="/hero.avif"
      fetchpriority="high">

<!-- don't block rendering -->
<style>/* critical CSS inlined */</style>
<script src="/app.js" defer></script>

04 / CRAWL CONTROL
