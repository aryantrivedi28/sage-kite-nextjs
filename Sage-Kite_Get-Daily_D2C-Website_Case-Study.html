The challenge

A new fitness-focused coffee brand needed a D2C website that could build demand before launch

Get Daily was new in the market, and its products were not shipping yet. The brand needed a direct-to-consumer website with a distinctive look for a young demographic, a fast landing page, and a way to start building an audience, getting user feedback and earning loyalty during the wait.

A new brand, not yet shipping

The products were not shipping yet, so the website had to do useful work before there was anything to deliver.

A young, fitness-focused audience

A D2C store for a young demographic needed a custom look and feel, designed in Figma, not a generic template.

Traction and feedback before going live

The brand wanted to start social media marketing, gather user feedback and build a community ahead of launch.

Performance

Website performance optimization: a landing page that loads in about 1.5 seconds, well below the 2.5 second threshold

The site was optimized for performance, keeping the landing page load time at about 1.5 seconds. That is well below the 2.5 second threshold, so first-time visitors from social media reach the page quickly.

Pre-order and waiting list

Pre-order and waiting list features that built demand before the product shipped

The brand was new and had some time before products started shipping. We added pre-order and waiting list features so it could start social media marketing and get traction with user feedback before going live. This also brought in organic users and helped build a loyal community.
