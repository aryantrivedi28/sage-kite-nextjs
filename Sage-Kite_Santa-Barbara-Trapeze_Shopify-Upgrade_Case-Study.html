The challenge

A growing Shopify catalog needed automation, clean data and urgency to convert event sales

Santa Barbara Trapeze needed to upgrade its existing digital presence to handle a growing catalog. The focus was on automation, data integrity, and creating a sense of urgency to drive conversions for specific events.

A catalog that keeps growing

More classes, camps, memberships and merchandise meant more products to list, sort and keep current by hand.

Data integrity and discoverability

Underlying data issues needed fixing, and new products needed SEO metadata so people could find them in search.

Urgency for specific events

Sale events needed a visible cue to prompt faster buying decisions and convert more of the traffic.

Theme upgrade

Shopify theme upgrade to Impulse: stronger merchandising for a larger catalog

We migrated the store to the Impulse theme to leverage its superior merchandising features. A larger inventory needs a theme built to present many products clearly, and the upgrade gave the store that foundation.

Automated merchandising

Shopify smart collections: automated merchandising that cuts manual work

We created Smart Collections based on logic rules, so product listings update automatically. A new product that matches a rule lands in the right collection without anyone adding it by hand, which reduces manual work for the client.

Data and SEO

Shopify SEO metadata and data integrity fixes so new products get discovered in search

We fixed underlying data integrity issues and updated SEO metadata, so new products were discoverable in search engines. Clean data keeps the catalog reliable, and clear titles and descriptions help search engines and shoppers understand each page.

  • Descriptive titlesSay what the page is, for whom and where.
  • Useful descriptionsInclude ages, dates and a starting price, which are the details a searcher is looking for.
  • Reliable data underneathFixed data integrity issues keep products, collections and metadata consistent.

Conversion tactics

Countdown timers on Shopify to create urgency for sale events and prompt faster purchasing decisions

We implemented urgency indicators, specifically countdown timers, to highlight sale events and prompt faster purchasing decisions. For an event with a fixed date, a visible clock makes the deadline concrete.
